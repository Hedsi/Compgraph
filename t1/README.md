# Інструменти малювання — завдання 1

## Опис

Реалізовано базові функції для роботи з растровими зображеннями за допомогою Python і NumPy.

- `canvas(w, h, color)` — створює полотно заданого розміру та кольору.
- `set_pixel(img, x, y, color)` — змінює колір одного пікселя, якщо координати перебувають у межах полотна.
- `save(img, path)` — зберігає зображення у файл.

## Вимоги

- Python 3
- NumPy
- OpenCV-Python

## Установлення

```bash
pip install numpy opencv-python
```

## Запуск

```bash
python demo.py
```

Результат зберігається у файлі `task01.png`.

## Перевірка роботи

Програма створює біле полотно, зафарбовує піксель `(0, 0)` червоним кольором і перевіряє поведінку для координат `(-5, 3)`. Оскільки ця точка лежить за межами полотна, функція `set_pixel` нічого не змінює.

Масив зображення має розмір `740 × 580 × 3` і тип `uint8`. Для звернення до пікселя використовується порядок `img[y, x]`.

## Завдання 2. Гамма-корекція

### Реалізація

У файлі `color.py` реалізовано функції:

- `to_linear(v)` — перетворює значення sRGB у лінійну яскравість.
- `to_srgb(l)` — перетворює лінійну яскравість у значення sRGB.
- `mix_colors(color1, color2)` — змішує два кольори в лінійному просторі.

Використано степеневу модель із гамою γ = 2.2:

- Лінійна яскравість: `L = (v / 255) ** 2.2`
- Перетворення назад: `v = 255 * L ** (1 / 2.2)`

Дробова частина під час перетворення назад відкидається.

### Чому 128 — неправильна відповідь для суміші чорного й білого?

Значення sRGB не пропорційні фізичній яскравості. Тому звичайне середнє `(0 + 255) / 2 = 127.5`, округлене до 128, не відповідає половині лінійної яскравості.

Спочатку кольори потрібно перевести в лінійний простір. Чорний має яскравість 0, а білий — 1. Їхнє середнє дорівнює 0.5. Після зворотного перетворення отримуємо приблизно 186.

Для значень `0, 0, 0, 255` середня лінійна яскравість дорівнює 0.25, а після перетворення назад отримуємо 136.

- Нижня — рівномірний розподіл лінійної яскравості.
